# Banner del canal de YouTube · Nadie Te Lo Explicó

`entrega/banner-youtube.png` (2560 × 1440, 1,7 MB) para subir en **YouTube Studio → Personalización → Marca → Imagen del banner**. El logo, el nombre, la bajada y los recuadros van dentro de la zona segura de 1546 × 423, que es lo único que se ve en el celular. Los íconos de los temas del canal (rayo, moneda, celular, pelota, ola, espejo, átomo y lupa) se ven en la compu y la tele.

`entrega/banner-zonas.png` es la misma imagen con las zonas marcadas, solo para revisar: no se sube.

```console
npx remotion still BannerYouTube entrega/banner-youtube.png
```
